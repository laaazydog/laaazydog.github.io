# 맥 로컬 제작 핸드오프

이 세션은 클라우드 컨테이너에서 돌아서 맥의 기존 쇼츠 제작 환경에 직접 손댈 수 없다. 아래 순서로 맥에서 이어서 진행한다.

## 1. 맥에서 시작하기
```bash
cd <기존 쇼츠 제작 프로젝트 폴더>
git clone -b claude/fear-mongering-analysis-shorts-jiufdp https://github.com/laaazydog/laaazydog.github.io.git ai-pace-fear-src
claude
```
그리고 아래 프롬프트를 붙여 넣는다.

## 2. 로컬 Claude Code에 줄 프롬프트
```
ai-pace-fear-src/shorts/2026-09-15-ai-pace-fear/ 폴더의 script.md(대본), lines.txt(문장별 TTS 입력 13줄), analysis.md(근거)를 읽고,
이 프로젝트의 기존 쇼츠 제작 파이프라인으로 9:16 쇼츠를 만들어줘.

요구사항
- 총 길이 50~60초. 빠른 전개: TTS 속도 기본 대비 +15~25%, 문장 간 무음 0.2초 이내, 컷은 문장마다 최소 1회, 긴 문장(2·3·11·12번)은 문장 안에서 한 번 더 컷.
- lines.txt 한 줄 = TTS 한 덩어리 = 자막 한 단위. 문장 텍스트는 바꾸지 말 것(숫자·인용 표현은 근거 확인된 것만 들어가 있음).
- 11번 문장은 "결과만 알려졌고, 과정은 아무도 모릅니다"까지 반드시 포함. '공격했다' 같은 단정 표현으로 바꾸지 말 것.
- 화면: 실존 인물 얼굴·회사 로고 사용 금지. 뉴스 클립을 쓸 경우 SBS 원 영상(https://youtu.be/JH7OcI466Jw)의 화면 인용 범위는 기존 채널 관행을 따를 것.
- 자막: 하단 1/3, 한 화면 2줄 이내, 숫자(6퍼센트, 70억 달러, 2조 달러)는 강조.
- 마지막 문장 뒤 0.8초 여백 후 페이드아웃.
완성되면 길이·해상도·파일 경로를 알려줘.
```

## 3. 이 브랜치에 있는 것
- `script.md` 빠른 전개용 대본 v2 (13문장, 약 330음절)
- `lines.txt` 문장별 TTS 입력 (가운뎃점을 쉼표로 바꿔 둠)
- `analysis.md` 정량 지표·출처·서사안
- `production.md` 클라우드에서 만든 초안 두 편의 기록(참고용, 결과물은 폐기해도 됨)
